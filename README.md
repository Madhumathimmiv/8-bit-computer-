# 8-Bit Breadboard Computer

The project is to build 8-bit breadboard computer modules from scratch. This repository includes schematics, design resources, and documentation of the project.

---

## Documentation

The complete documentation for this project, including schematics and explanations, can be viewed in this [Mathcha document](https://www.mathcha.io/editor/oM5KOI1LFkXh89EqXoCv3zrmeHExLq31UoKomEG?embedded=true), created using [Mathcha.io](https://www.mathcha.io/).

The documentation covers:
- Circuit schematics
- Components required
- Module working explanation
- Images of modules on breadboard

---

## Repository Contents

This repository includes:
- `/schematics/` - Circuit diagrams and images related to the project.
- `README.md` - This file, containing an overview of the project.

---

## Requirements

To build the 8-bit breadboard computer, you will need:
- Basic electronics components (Refer to the documentation for complete Bill of Materials for each module).
- Access to a power supply.
- Schematic files (provided in this repository) or circuit diagrams.
